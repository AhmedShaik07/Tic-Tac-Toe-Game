## Tic Tac Toe Game 🎮  

A simple and fun **Tic Tac Toe** game built using **HTML**, **CSS**, and **JavaScript**, and deployed using **AWS Services**. Play it anytime, anywhere, and enjoy a classic game experience right in your browser!  

---

## Features  
- **Interactive Gameplay:** Play against a friend with a clean and responsive interface.  
- **Real-time Feedback:** Highlights the winning combination or announces a draw.  
- **Minimalist Design:** Simple yet engaging UI for an optimal gaming experience.  
- **Accessible Anywhere:** Deployed on AWS, making it available globally.  

---

## How to Play  
1. Open the game in your browser.  
2. Player X starts the game, followed by Player O.  
3. Take turns to mark a square on the 3x3 grid.  
4. The first player to align three symbols in a row, column, or diagonal wins!  
5. If all squares are filled without a winner, it’s a draw.  

---

## Technologies Used  
- **HTML**: For structuring the game layout.  
- **CSS**: For styling the grid and overall design.  
- **JavaScript**: For game logic and interactivity.  
- **AWS Services**: For deploying and hosting the game online.  

---

## Deployment  
The game has been deployed using the following AWS services:  
- **Amazon S3**: Static website hosting.  
- **AWS CloudFront** (Optional): For faster content delivery.
